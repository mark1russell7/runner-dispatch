runner-dispatch

One-job CI runners for trusted jobs: a source of queued jobs, trust rules as data, and a provider that makes one machine for one job.

Which runs get a machine

The dispatcher makes a machine only for a trusted run. Pick a sample run, or change a field or a rule. At each change, the page calls decide of the package.

The run

      The life of one machine

      Each machine does one job, and then the dispatcher destroys it. Each state has a timer, so no machine stays forever. Send events, and see the state, the timer and the requests of the dispatcher. The page uses MACHINE_LIFECYCLE, advance and waitOf of the package.

        The log

          The times of a machine

          Each time is in seconds. A change starts the life again.
